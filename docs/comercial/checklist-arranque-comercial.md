# Checklist de arranque comercial — EsarIA

Objetivo: tener lo mínimo necesario para salir a validar con negocios reales sin montar una estructura pesada antes de tiempo.

Importante: antes de emitir una factura o prestar un servicio remunerado conviene confirmar con una asesoría cuándo debes darte de alta. No bases el proceso en facturar primero y regularizar después sin revisarlo.

---

## Fase 1 — Antes de contactar empresas

Prioridad máxima. Sin esto, es fácil sonar genérico o improvisado.

- [ ] Oferta inicial concreta definida.
- [ ] Web o página básica revisada y con contacto claro.
- [ ] Email profesional funcionando.
- [ ] Demo funcional preparada para enseñar.
- [ ] Guion de diagnóstico listo.
- [ ] Plantilla de propuesta lista.
- [ ] Mensajes de prospección preparados.
- [ ] Lista inicial de 20-30 negocios locales.

---

## Oferta inicial recomendada

No salir al mercado diciendo solo "automatizo empresas".

Mensaje recomendado:

> Ayudo a negocios locales de Valladolid a ahorrar tiempo automatizando tareas repetitivas como citas, recordatorios, respuestas frecuentes por WhatsApp y seguimiento de clientes.

Servicios iniciales a priorizar:

1. Automatización de citas y recordatorios.
2. Respuestas frecuentes por WhatsApp/email.
3. Seguimiento de presupuestos o clientes.
4. Captura ordenada de datos desde formularios.

Sectores prioritarios:

- Clínicas y centros de fisioterapia.
- Centros de estética.
- Talleres.
- Gimnasios o centros deportivos.
- Academias.

---

## Demo mínima enseñable

La demo no tiene que ser perfecta. Tiene que explicar el valor en 3 minutos.

Flujo recomendado:

1. Un cliente rellena un formulario.
2. El dato entra en una hoja/CRM simple.
3. El negocio recibe una notificación.
4. El cliente recibe una confirmación.
5. Se crea una tarea o recordatorio de seguimiento.

Checklist de demo:

- [ ] Se puede enseñar en directo sin depender de datos reales.
- [ ] Usa nombres ficticios.
- [ ] No contiene datos personales reales.
- [ ] Tiene una explicación simple: problema, solución, resultado.
- [ ] Está preparada una versión para clínicas y otra genérica.

Frase para presentarla:

> Esto es una demo sencilla. No es un caso real de cliente. Sirve para ver cómo podría funcionar un proceso parecido en vuestro negocio.

---

## Fase 2 — Primeras reuniones

Objetivo: conseguir aprendizaje real, no cerrar a cualquier precio.

- [ ] Hacer diagnóstico de 20-45 minutos.
- [ ] Detectar un solo problema concreto.
- [ ] Confirmar herramientas actuales del negocio.
- [ ] Estimar tiempo perdido o errores evitables.
- [ ] No prometer nada técnico antes de revisar viabilidad.
- [ ] Enviar propuesta solo si hay encaje real.

Regla:

> Si no puedes explicar el problema en una frase, no prepares propuesta todavía.

Ejemplo válido:

> El centro gestiona unas 35 citas semanales por WhatsApp y pierde tiempo confirmando y recordando manualmente cada una.

---

## Fase 3 — Antes de aceptar un cliente


- [ ] Revisar viabilidad técnica.
- [ ] Definir alcance exacto por escrito.
- [ ] Definir qué no está incluido.
- [ ] Acordar precio, forma de pago y calendario.
- [ ] Confirmar situación fiscal/legal antes de cobrar o facturar.
- [ ] Tener contrato o aceptación formal por escrito.
- [ ] No empezar con accesos críticos sin acuerdo claro.

---

## Lo que no debes prometer

- Ventas garantizadas.
- Ahorros exactos sin medirlos.
- Que la IA resolverá cualquier consulta.
- Integraciones sin comprobar APIs, permisos o límites.
- Automatizar procesos que el negocio no tiene claros.
- Gestionar datos sensibles sin revisar bien el caso.

---

## Próximo paso recomendado

1. Elegir un sector principal para las primeras 2 semanas.
2. Preparar una demo adaptada a ese sector.
3. Crear una lista de 20 negocios locales.
4. Contactar de forma manual y personalizada.
5. Aprender de las respuestas y ajustar la oferta.
