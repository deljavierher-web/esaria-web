## Qué no incluye

- [ ] Nuevas automatizaciones no incluidas en la propuesta.

- [ ] Las cuentas principales pertenecen al cliente.

- [ ] EsarIA tiene solo los permisos necesarios.
- [ ] Los accesos se pueden revocar al terminar el servicio.
- [ ] No quedan datos del cliente en cuentas personales de EsarIA.

## Mantenimiento mensual

Definir solo si el cliente lo contrata.

Incluye:

- [ ] Revisión básica de que los flujos siguen activos.
- [ ] Corrección de fallos de configuración.
- [ ] Ajustes menores acordados.
- [ ] Soporte por WhatsApp/email dentro del horario acordado.

No incluye:

- [ ] Nuevas automatizaciones completas.
- [ ] Cambios grandes de proceso.
- [ ] Costes de herramientas externas.
- [ ] Problemas provocados por cambios de acceso o cuentas del cliente.

Condiciones recomendadas:

```text

```
