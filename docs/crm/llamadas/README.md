# Llamadas CRM

Carpeta para revisar llamadas comerciales de EsarIA.

## Estructura

- `audios/`: grabaciones originales de llamadas.
- `transcripciones/`: texto transcrito de cada llamada.
- `analisis/`: revisión de puntos fuertes, fallos y mejoras.

## Nombre recomendado de archivos

Usa este formato para que sea fácil asociar cada audio con el lead:

```txt
YYYY-MM-DD_LEAD-202605-001_nombre-negocio.mp3
```

Si no sabes el ID del lead:

```txt
YYYY-MM-DD_nombre-negocio.mp3
```

## Qué revisar en cada llamada

- Apertura: si queda claro quién llama y por qué.
- Filtro: si se consigue llegar a la persona adecuada.
- Dolor: si se pregunta por problemas reales antes de vender.
- Propuesta: si se explica de forma sencilla y concreta.
- Cierre: si queda una siguiente acción clara.
- Objeciones: qué respuestas funcionaron y cuáles no.
