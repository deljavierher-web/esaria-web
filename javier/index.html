1. VisionParking AI (`@ParkingCasetas_bot`)

            

              Sistema de verificación instantánea de matrículas desplegado en el control de accesos de las Casetas Regionales (Servisecur, Valladolid). Sustituye la búsqueda manual en listas impresas bajo presión de tráfico.
            

            
    
              
  • Cadena de Visión con Failover: Prioriza Qwen-VL-Flash para latencia ~1s y conmuta automáticamente a Gemini Flash o GPT-4o-mini si hay saturación de cuota.
    • 
              
  • Normalización Española Robusta: Soporta matrículas modernas (1234-BBB) y provinciales antiguas (VA-1234-AB), además de búsqueda ultrarrápida por voz/texto en <0.2s.
    • 
              
  • Registro y Panel Web: Botones inline para fichar la entrada en vivo (registros.csv) y dashboard web de vehículos dentro del recinto.
    • 
            

          

          
# Extracto real de ocr.py — Normalizador + Cadena de Failover Multimodal
def extract_plate_from_text(text: str) -> Optional[str]:
    text = text.upper().strip()
    # 1) Formato moderno: 4 dígitos + 3 consonantes (ej. 4821 MNP)
    m_mod = re.search(r'([0-9]{4})\s*[- ]?\s*([BCDFGHJKLMNPRSTVWXYZ]{3})', text)
    if m_mod:
        return f"{m_mod.group(1)}{m_mod.group(2)}"
    # 2) Formato provincial (ej. VA 1234 AB)
    m_prv = re.search(r'([A-Z]{1,2})\s*[- ]?\s*([0-9]{4})\s*[- ]?\s*([A-Z]{1,2})', text)
    if m_prv:
        return f"{m_prv.group(1)}{m_prv.group(2)}{m_prv.group(3)}"
